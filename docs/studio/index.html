Studio

Creative technology services

Commissioned and collaborative work runs through Modular Muse, my studio. Custom hardware and software for interactive experiences, exhibits, and instruments — from first concept through a system that survives a public run.

What that looks like

  • Interactive installations and exhibits, built to be handled by the public
  • Custom electronics: embedded systems, PCB design and layout, motor and sound actuation
  • Software for desktop, mobile, and embedded — C/C++, JavaScript, node.js, openFrameworks, Processing, Max/MSP, Pd
  • Technical direction and prototyping alongside artists, exhibit designers, and researchers
