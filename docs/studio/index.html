Studio

Creative technology services

Commissioned and collaborative work runs through my studio, Modular Muse. Custom hardware and software for interactive experiences, exhibits, and instruments — from brainstorming first concepts through iterative prototypes to a system that survives the public run.

What that looks like

  • Expressive, Interactive installations and exhibits, built to be handled by the public
  • Custom electronics: embedded systems, PCB design and layout, motor and sound actuation
  • Software for desktop, mobile, and embedded — C/C++, JavaScript, openFrameworks, Processing, Max/MSP, Pd
  • Technical direction and prototyping alongside artists, exhibit designers, and researchers
